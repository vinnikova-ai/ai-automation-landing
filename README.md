# AI-Automation & Telegram Web Apps Landing Page ❄️🍏

Премиальный демонстрационный MVP-кейс (посадочная страница с интерактивной воронкой продаж), разработанный в рамках челленджа Winter Arc 2026. Проект создан для демонстрации навыков продуктовой упаковки, веб-верстки и проектирования пользовательских сценариев (UX/UI) для ИТ-рынка.

* **Действующая ссылка на сайт (GitHub Pages):** [https://vinnikova-ai.github.io/ai-automation-landing/](https://vinnikova-ai.github.io/ai-automation-landing/)

---

## 🎨 Визуальная концепция и дизайн-система
Интерфейс выполнен по канонам строгого технологичного минимализма Apple с использованием современных цветовых oklch-токенов из TweakCN:
* **Архитектура:** Низкая визуальная плотность, отсутствие тяжелых теней и лишних рамок. Глубина интерфейса достигается за счет чередования матовых графитовых поверхностей и свободного пространства ("воздуха").
* **Типографика:** Фирменная плотная посадка заголовков Apple Tight (зажатый межбуквенный интервал `letter-spacing: -0.03em`) на базе шрифта **Manrope**.
* **Маркеры:** Использование моноширинного шрифта **JetBrains Mono** в верхнем регистре (UPPERCASE) для структурных подзаголовков (eyebrows).

## 🗺️ Анатомия воронки продаж (5 экранов)
Страница построена по канонам продуктового маркетинга и последовательно ведет пользователя по этапам квалификации:
1. **Hero Section (Главный экран):** Чёткое ценностное предложение (оффер) лаборатории автоматизации и яркий призыв к действию (CTA).
2. **Лид-магнит:** Интерактивный блок сбора контактов (Имя и Telegram @username) для скачивания бесплатного ИИ-гайда по оптимизации бизнес-процессов.
3. **Интерактивный ИИ-Квиз:** Трёхшаговый адаптивный опросник для квалификации лида (определение сферы бизнеса, целей автоматизации и платформы функционирования).
4. **Калькулятор стоимости:** Монохромный блок на чистом JavaScript для прозрачного, динамического расчета стоимости внедрения MVP-компонентов в реальном времени.
5. **Минималистичный футер:** Изящное завершение воронки по стандартам fine-print со ссылками на портфолио в GitHub и ИТ-витрину на Хабр Карьере.

---

## 🛠️ Стек технологий
* **Frontend:** HTML5, адаптивная кроссбраузерная верстка, **Tailwind CSS v4** (core-play через CDN-скрипт) для управления сеткой и отступами, чистый JavaScript (**Vanilla JS**) для асинхронной логики квиза и калькулятора.
* **Хостинг:** Бесплатный статический сервер **GitHub Pages** (автоматический деплой из ветки `main`).
