# DESIGN.md — Дизайн-система воронки Vinnikova.AI (Стиль Apple Dark)

## 1. Атмосфера и визуальная концепция
* Философия: Photography-first интерфейс. Минималистичные карточки, много свободного пространства ("воздуха"). Отсутствие декоративных градиентов и тяжелых теней.
* Скругления: border-radius: 0.5rem; (8px) для карточек и полей ввода, и полные пилюли (9999px) для главных кнопок.

## 2. Цветовые токены (Палитра OKLCH из TweakCN)
Принудительно фиксируем премиальную темную тему:
* --background: oklch(0.1776 0 0); /* Глубокий матовый фон графита */
* --card: oklch(0.2134 0 0);       /* Панели квиза и калькулятора стоимости */
* --foreground: oklch(0.9491 0 0); /* Мягкий контрастный белый текст */
* --primary: oklch(0.9247 0.0524 66.1732); /* Фирменный белый акцент для кнопок (CTA) */
* --border: oklch(0.2351 0.0115 91.7467);   /* Ультратонкие современные границы блоков */
* --muted-foreground: oklch(0.7699 0 0);    /* Приглушенный серый для подзаголовков */

## 3. Типографика (По канонам Apple tight)
* Главные заголовки: Крупный технологичный шрифт (Manrope). Межбуквенный интервал зажимается (letter-spacing: -0.03em), создавая плотную посадку букв Apple.
* Текстовые брови (Eyebrows): Моноширинный шрифт (JetBrains Mono) в верхнем регистре (UPPERCASE) с увеличенным интервалом (letter-spacing: 0.15em).
